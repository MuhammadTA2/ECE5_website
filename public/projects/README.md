# Project media

Create one folder per project, using the same slug as the project record in `src/projects.ts`.

Recommended structure:

```text
public/projects/your-project-slug/
├── preview.jpg
├── build-01.jpg
├── build-02.jpg
└── result.jpg
```

Use web-friendly JPG, PNG, AVIF, or WebP files. Preview images work best at a landscape ratio around 3:2; gallery images may use any ratio.
